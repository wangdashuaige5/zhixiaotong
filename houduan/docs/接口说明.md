# 详细设计接口对照

以用户提供的详细设计为依据，共82个设计接口。下表说明请求字段与用途；新增联调接口见运行后的Swagger或openapi.json。

除登录、刷新、支付验签回调外，/api接口均需 Authorization: Bearer <access_token>。Map请求字段按表中说明填写，不代表可以任意写入数据库字段。

ID请求可用数字或数字字符串；ID与DECIMAL输出为字符串；JSON字段输出为对象或数组；日期时间输出带+08:00。分页使用page_no、page_size（最多100），响应data={items,total,page_no,page_size}。code=0表示成功；400参数错误，401身份无效，403越权，404不可见或不存在，409状态或约束冲突，429限流，503依赖未配置或不可用。

课程路径中的{id}是course.id，具体开课必须带teaching_class_id；选课提交使用batch_course_id。审批{id}分别对应当前业务要求的审批单ID，不能混用申请ID。设备登记比设计多校验一次password，scope_data由服务端构建。

## 用户认证与个人中心

|名称|方法和路径|字段与说明|
|---|---|---|
|用户登录|`POST /api/auth/login`|输入user_name、password、device_code；返回access_token、refresh_token和权限摘要|
|刷新令牌|`POST /api/auth/refresh`|输入refresh_token；返回新令牌对，旧刷新凭证失效|
|当前用户|`GET /api/users/me`|返回本人资料、角色及允许的功能入口|
|更新资料|`PUT /api/users/profile`|仅允许维护邮箱、手机和头像等白名单字段|
|退出登录|`POST /api/auth/logout`|撤销当前会话，重复调用返回成功|
|修改密码|`PUT /api/users/password`|输入old_password、new_password；成功后重新登录|

## 课表与课程中心

|名称|方法和路径|字段与说明|
|---|---|---|
|查询课表|`GET /api/timetables`|semester_id、week_no；返回本人课表，越界周次返回400|
|课程详情|`GET /api/courses/{id}`|id为course.id；可带teaching_class_id查看开课详情|
|课程资料|`GET /api/courses/{id}/resources`|必须指定teaching_class_id；返回已发布且可见资源|
|考试安排|`GET /api/exams/me`|按semester_id查询本人考试或监考安排|
|教学评价|`POST /api/enrollments/{id}/evaluation`|输入total_score、item_scores、comment；每笔选课最多一条评价|

## 选课管理

|名称|方法和路径|字段与说明|
|---|---|---|
|可选课程|`GET /api/enrollments/options`|输入batch_id及筛选条件；返回batch_course_id和参考余量|
|提交选课|`POST /api/enrollments`|输入batch_course_id、request_key；返回id、enroll_status、result_note|
|退选|`DELETE /api/enrollments/{id}`|id为enrollment.id；逻辑退选，不物理删除记录|
|我的选课|`GET /api/enrollments/me`|按semester_id、enroll_status分页查询本人结果|

## 作业与教学资源

|名称|方法和路径|字段与说明|
|---|---|---|
|创建作业|`POST /api/courses/{id}/assignments`|输入teaching_class_id、assignment_title、content、deadline；返回assignment_id|
|作业列表|`GET /api/courses/{id}/assignments`|指定teaching_class_id，按权限返回作业及本人提交状态|
|提交作业|`POST /api/assignments/{id}/submissions`|输入content、file_ids；返回submission_id和submit_round|
|批改作业|`PUT /api/submissions/{id}/grade`|输入score、feedback、action；action为grade、return或publish|
|发布课程资源|`POST /api/courses/{id}/resources`|输入teaching_class_id、resource_title、file_id、visible_scope|

## 成绩管理

|名称|方法和路径|字段与说明|
|---|---|---|
|成绩草稿|`PUT /api/courses/{id}/grades`|输入teaching_class_id及成绩items；每项含enrollment_id、分项、exam_flag、version|
|提交审核|`POST /api/courses/{id}/grades/submit`|输入teaching_class_id；返回review_id、review_round及异常提示|
|审核成绩|`POST /api/grade-reviews/{id}`|输入decision和review_comment；decision为通过或退回|
|我的成绩|`GET /api/grades/me`|按学期查询本人grade_status=3的成绩|
|申请更正|`POST /api/grades/{id}/changes`|提交拟改分项、版本和change_reason；原值由服务端读取|
|审核更正|`POST /api/grade-changes/{id}/decision`|输入decision、review_comment；禁止申请人自审|

## 请假与销假

|名称|方法和路径|字段与说明|
|---|---|---|
|创建请假单|`POST /api/leaves`|输入leave_type、start_time、end_time、leave_reason、file_ids及提交动作|
|待审批列表|`GET /api/leaves/pending`|返回本人有权审批且当前节点待办的请假单|
|审批请假|`POST /api/leaves/{id}/approve`|输入apply_round、node_order、decision、opinion；返回最新状态|
|销假|`POST /api/leaves/{id}/close`|本人对已通过请假销假；重复请求不重复操作|
|我的请假|`GET /api/leaves/me`|查询本人请假和可见审批轨迹|
|修改与重提|`PUT /api/leaves/{id}`|仅草稿或退回状态可改；重提时增加申请轮次|
|撤回请假|`POST /api/leaves/{id}/withdraw`|审批中且尚未终审时允许撤回，取消剩余待办节点|

## 校园卡与图书服务

|名称|方法和路径|字段与说明|
|---|---|---|
|查询卡余额|`GET /api/cards/balance`|返回本人余额、account_status和sync_time；缓存值标注同步时间|
|创建充值订单|`POST /api/cards/recharges`|输入amount、pay_channel、request_key；返回order_no和支付状态|
|查询充值结果|`GET /api/cards/recharges/{id}`|只返回本人订单；支付跳转成功不代表入账成功|
|支付结果通知|`POST /api/integrations/payments/callback`|接收渠道通知；按学校协议验签、验金额、验订单和防重放|
|查询卡流水|`GET /api/cards/transactions`|本人按日期分页查询充值、消费与退款流水|
|检索图书|`GET /api/library/books`|按书名、作者、分类检索书目和可借数量|
|我的借阅|`GET /api/library/loans/me`|返回本人借阅、应还时间和可续借状态|
|续借图书|`POST /api/library/loans/{id}/renew`|服务端校验本人、借阅状态和学校续借规则|
|预约图书|`POST /api/library/reservations`|输入book_id、request_key；返回排队状态|
|取消预约|`DELETE /api/library/reservations/{id}`|仅取消本人有效预约；保留历史记录|
